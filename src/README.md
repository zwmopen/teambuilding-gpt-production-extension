# 团建内容工作台 · GPT 助手扩展

这是寄生在真实 ChatGPT 页面里的团建创作外挂。安装后形成三个工作区：

1. 左侧：最新版会话树脚本，保留分组、提示词、下载和工作包按钮。
2. 中间：ChatGPT 原生聊天界面，不复制、不伪造登录和聊天。
3. 右侧：团建创作生产舱。上半区读取成品库，下半区读取“图片 + 文案”素材帖子；点击“传 GPT”或拖到中间即可放入当前对话。

成品库和素材库都可以直接粘贴本地绝对路径并回车。扩展不直接获得整个磁盘权限，而是通过只监听本机回环地址的团建内容工作台读取已授权目录。

生产防重复读取现有一键工作包的独立历史库：整组图片 SHA-256 是确定重复依据，64 位 dHash 只做视觉近似预警。手机/公众号是否使用过由分发台账单独判断。

## 本地测试

1. 先启动团建内容工作台，确认 `http://127.0.0.1:4327` 可打开。
2. 在 Edge 的“扩展”页面打开开发人员模式。
3. 选择“加载解压缩的扩展”，指向当前目录。
4. 打开真实 `https://chatgpt.com/`，右侧应出现“团建创作生产舱”。

扩展只读取本机回环地址，不把目录索引传到外网。旧油猴脚本与扩展并行测试时可能出现重复按钮；扩展验证通过后，应关闭旧油猴脚本，只保留扩展内置的最新版副本。
