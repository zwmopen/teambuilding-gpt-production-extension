# 架构

## 0.1.8 内容指纹

- 工作台只在用户准备上传选定素材时计算指纹，避免全库扫描造成卡顿。
- 单文件 SHA-256 排序后再次聚合，因此改文件名或调整文件顺序不会绕过防重。

## 0.1.7 素材使用台账

- `POST /api/extension/material-use` 接收 `prepared` 与 `used` 两阶段事件。
- 工作台在本地运行数据中持久化台账，素材目录保持只读式管理。
- `/api/materials` 把已有状态返回拓展，拓展据此显示状态和阻止重复上传。

## 0.1.6 本地桥接

- `GET /api/extension/product-tree`：读取成品根目录下的完整目录树，包含普通目录和文件。
- `POST /api/extension/work-package`：由工作台直接执行现有 PowerShell 工作包脚本。
- 页面内“打包作品”通过拓展后台消息调用上述接口，不再默认打开 `cgpt-workpkg://` 或 VBS。
- 手机分发台账与成品文件树相互独立，避免分发过滤条件误删文件管理视图中的目录。

```text
ChatGPT 原生左侧栏
  + 会话树模块
        │
ChatGPT 原生聊天区 ── 扩展上传桥 ── 右侧生产舱
                                      │
                            127.0.0.1:4327
                                      │
              团建内容工作台（路径、文件流、去重状态）
                     ├─ 素材库
                     ├─ 成品库
                     └─ 作品历史数据库（只读状态）
```

扩展采用 Manifest V3。`gm-shim.js` 只为内置会话树模块提供兼容接口；用户不需要安装油猴。`sidebar.js` 负责右侧生产舱、路径设置、懒加载和上传到当前 ChatGPT。`background.js` 只承载浏览器下载与工具栏开关。

目录来源优先级：

```text
工作台当前有效路径 > 扩展本地保存路径 > 代码内置首次启动路径
```

扩展只保存路径字符串，不复制本地素材、成品或历史数据库。
