## 0.2.4 当前事实

- 工作台内置模式已形成串行自动闭环：真实附件上传 → 迁移计划 → 可选自动确认 → 新图片检测 → 小红书文案检测 → 精确批次下载 → 本地工作包校验。
- 每次任务生成 `YYYYMMDD-HHMMSS-xxxx` 批次号；图片下载名包含批次号、序号和总数，本地打包只接收该批次并校验图片张数和 TXT。

- 生产间隔由工作台设置为随机范围，属于常规队列节奏；平台验证和限流必须暂停，不能自动规避。
- 已完成扩展语法与架构自动测试；工作台桌面隔离烟测确认 0.2.4 快照可加载、账号隔离与任务桥可用。隔离测试账号停在 ChatGPT 登录页，因此 0.2.4 登录后的真实付费生成仍需用户首次登录后执行一套验收。
